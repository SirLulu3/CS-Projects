01 / Expressions, not shortcuts

Functions become lambdas. Branches become conditional expressions. No if:, for:, def:, semicolon-packed statements, or dynamic execution wrappers appear in the result.

02 / Continuations + a trampoline

Each statement becomes a small function returning the next step. An iterative runner follows these continuations, so loops do not grow the call stack.

03 / Real parsing, local compilation

A Python syntax tree drives the transformation. The page parses your source without running it. The generated expression runs in Python 3 with your usual dependencies.

Supported Python & practical limits

Supported: assignments and unpacking; expressions, slices, dictionaries and comprehensions; if / elif / else; for and while with break, continue and loop else; functions, recursion, closures, positional/keyword/default arguments, *args and **kwargs; return, global, nonlocal; ordinary imports; assertions and explicit raises.

Not yet supported: classes, decorators, annotations, try / except / finally, with, async code, generator functions, pattern matching, del, assignment expressions, relative/star/future imports, bare raise, and augmented assignments to attributes or subscripts. These produce errors; there is no wrapper fallback.

This is a practical Python subset, not a compiler for every possible program. Generated functions and namespaces differ internally: stack traces, frame inspection, function metadata, pickling, self-reading code, finalization timing and module-global inspection are not preserved. Dynamic execution and common introspection operations are rejected. Ordinary function recursion still has a depth limit. Assertions remain active even with Python’s -O flag. A StopIteration escaping a translated statement may become RuntimeError in the trampoline.

Lambda, dictionary and slice colons are allowed; statement-block colons are not. Output is one physical line, usually longer than the original. The parser accepts the Python syntax supported by its bundled runtime; use Python 3.14 for matching syntax support. UTF-8 input is limited to 256 KiB. The Pyodide runtime is bundled in this HTML file. No runtime downloads or server connection are needed. Local files automatically use compatibility mode without workers; large inputs may briefly pause the page. Source is never sent to a server.
